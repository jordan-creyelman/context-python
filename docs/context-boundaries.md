# Context boundaries

When `context-python` and `context-github` are active together:

- `context-python` is the source of truth for Python code, tests, architecture, and Python learning progress.
- `context-github` is the source of truth for Git, GitHub, branches, commits, pull requests, reviews, merges, tags, and CI workflow.
- Do not duplicate Git/GitHub workflow rules in `context-python`.

Python manages Python. GitHub manages Git/GitHub.
